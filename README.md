# Sowmiya A — Professional AI & Full-Stack Developer Portfolio

A production-ready, highly responsive personal portfolio website engineered for **Sowmiya A**. Built with modern HTML5, CSS3, JavaScript (ES6+), glassmorphism UI principles, and real-time GitHub API integration.

---

## 🌟 Key Features

- **Modern Glassmorphism UI**: Dark mode default with smooth Light Mode toggle.
- **Dynamic GitHub Integration**: Live stats, top languages, repository count, and recent projects fetched via GitHub API (`@sowmi151`).
- **Interactive Mechanics**:
  - Custom canvas particle animation background.
  - Smooth typing hero banner.
  - Interactive project filtering.
  - Smooth scroll progress indicator & back-to-top feature.
  - Custom fluid cursor tracker.
- **Working Contact Form**: Integrated with EmailJS for direct inbox delivery.
- **Lighthouse Optimized**: Standard compliant semantics, fast load times, and accessible color contrast.
